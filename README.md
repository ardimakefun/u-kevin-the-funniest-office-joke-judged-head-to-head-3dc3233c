One original one-line joke about office life, written for the
[make.fun bounty "The Funniest Office Joke"](https://make.fun/c/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c)
($2, top 10).

## Run

```sh
node main.ts   # writes the joke to /output/entry.txt
```

Deterministic Node 22+ program, stdlib only — no network, no randomness.
`main.ts` fail-fast gates the joke against the bounty rules before writing:
UTF-8 text, 1–200 characters, not only whitespace, exactly one line.

## The joke

> I asked HR for a raise and they gave me a plant — apparently growth opportunities are literal now.

(98 characters, 19 words, one line.)
